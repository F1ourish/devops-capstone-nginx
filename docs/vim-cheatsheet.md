## 1) Режимы и самое необходимое

* Normal mode — “режим команд”. Большинство действий делается тут.

* Insert mode — “режим ввода текста”.

* Visual mode — “режим выделения”.

### Команды:

* `Esc` — вернуться в Normal (самая важная клавиша).

* `i` — вставка перед курсором (вход в Insert).

* `a` — вставка после курсора (удобно дописать символ справа).

* `o` — новая строка ниже + Insert (быстро добавить строку в конфиге).

* `O` — новая строка выше + Insert.

## 2) Навигация (быстро)

* `h j k l` — базовое движение курсора (влево/вниз/вверх/вправо).

* `w` — на начало следующего слова (быстро прыгать по параметрам).

* `b` — на начало предыдущего слова.

* `e` — на конец слова (иногда удобнее чем `w`).

### По строке:

* `0` — в начало строки (позиция 0).

* `^` — на первый НЕпробельный символ строки (часто лучше, чем 0).

* `$` — в конец строки.

### По файлу:

* `gg` — в начало файла.

* `G` — в конец файла.

* `{` / `}` — прыжок по абзацам/пустым строкам (удобно в markdown).

### Постранично:

* `Ctrl+d` — вниз на пол-экрана (down).

* `Ctrl+u` — вверх на пол-экрана (up).

### Точный прыжок в строке:

* `f{char}` — найти символ `{char}` на текущей строке и встать на него (find).

* `t{char}` — найти символ и встать ПЕРЕД ним (till).
  Пример: `t"` удобно, чтобы оказаться перед кавычкой.

## 3) Редактирование (часто используемое)

### Удаление/вырезание:

* `x` — удалить символ под курсором (как Delete).

* `dd` — удалить строку целиком (и положить в буфер — можно вставить обратно).

* `D` — удалить от курсора до конца строки (быстро чистить хвост строки).

* `dw` — удалить слово от курсора (delete word).

### Копирование/вставка:

* `yy` — скопировать строку (yank).

* `p` — вставить ПОСЛЕ курсора/строки.

* `P` — вставить ДО курсора/строки.

### Отмена/повтор:

* `u` — undo (отмена последнего действия).

* `Ctrl+r` — redo (вернуть отменённое).

### Полезное:

* `.` — повторить последнее изменение (очень мощно для однотипных правок).

## 4) “Текстовые объекты” (очень удобно для конфигов)

Идея: команда = действие (d/c/y) + “что” (объект).

### Самое частое:

* `ciw` — change inner word: заменить слово целиком, не думая о границах.

* `diw` — delete inner word: удалить слово целиком.

* `yiw` — yank inner word: скопировать слово.

### Внутри кавычек/скобок:

* `ci"` — заменить текст внутри двойных кавычек.

* `ci'` — внутри одинарных кавычек.

* `ci(` / `ci{` — внутри круглых/фигурных скобок.

* `di"` / `di(` и т.д. — то же самое, но удалить.

### Абзацы (часто полезно в markdown):

* `dap` — delete a paragraph: удалить абзац целиком.

* `vip` — visual inner paragraph: выделить абзац.

## 5) Поиск

* `/pattern` — поиск вперёд по файлу.

* `?pattern` — поиск назад.

* `n` — следующее совпадение.

* `N` — предыдущее совпадение.

### Быстрый поиск “слова под курсором”:

* `*` — искать это слово вперёд.

* `#` — искать назад.

### Подсветка совпадений:

* `:set hlsearch` — включить подсветку.

* `:set nohlsearch` — выключить.

* `:noh` — убрать подсветку до следующего поиска (самый удобный вариант).

## 6) Замена (substitute)

Синтаксис: `:[диапазон]s/что/на_что/[флаги]`

* `:s/old/new/` — заменить первое совпадение в текущей строке.

* `:s/old/new/g` — заменить все совпадения в текущей строке.

* `:%s/old/new/g` — заменить по всему файлу (% = весь файл).

* `:%s/old/new/gc` — то же, но с подтверждением (c = confirm).
  В confirm обычно: `y` yes, `n` no, `a` all, `q` quit.

### Диапазоны:

* `:10,20s/old/new/g` — только строки 10–20.

### Слово целиком:

* `:%s/\<old\>/new/g` — меняет только “old” как отдельное слово (не трогает “folder” и т.п.).

### Посчитать совпадения без замены:

* `:%s/old/new/gn` — покажет количество совпадений (удобно перед массовой заменой).

## 7) Несколько файлов/окон

### Буферы (открытые файлы):

* `:e file` — открыть файл.

* `:ls` — список буферов.

* `:b N` — переключиться на буфер N.

* `:bd` — закрыть текущий буфер.

### Окна:

* `:sp` — split (разделить горизонтально).

* `:vsp` — vertical split (вертикально).

* `Ctrl+w w` — переключаться между окнами.

## 8) Практика для наших конфигов (nginx/compose/runbook)

* Найти `/healthz`: `/healthz → n`.

* Быстро поменять `oops` → `ok` по файлу с подтверждением: `:%s/oops/ok/gc`

* Найти все `location`: `/location`

* Повторить правку несколько раз: сделай одно изменение и жми `.` чтобы повторять.
